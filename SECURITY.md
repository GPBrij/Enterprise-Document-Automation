# Security Policy

## Do not commit

- Passwords, secrets, API keys, tokens, or credentials
- Personal contact details or identity information
- Real tenant URLs, server names, machine names, or private IP inventories
- Customer, employer, banking, tender, or confidential business information
- Raw endpoint reports, scan results, packet captures, or logs

## Safe reporting

Use synthetic examples and reserved documentation values. Report a repository security concern privately to the repository owner rather than publishing sensitive details in an issue.
