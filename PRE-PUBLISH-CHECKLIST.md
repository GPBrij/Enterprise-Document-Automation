# Pre-publication checklist

## Source quality

- [ ] All scripts parse with zero errors
- [ ] Every script has a clear filename
- [ ] Every script has comment-based help or adequate repository documentation
- [ ] Assessment and remediation behavior are clearly distinguished

## Privacy and confidentiality

- [ ] No personal email addresses or telephone numbers
- [ ] No customer, employer, tender, banking, or confidential business information
- [ ] No real tenant URLs, machine names, usernames, serial numbers, or private IP addresses
- [ ] No credentials, keys, tokens, secrets, or connection strings
- [ ] No raw logs, reports, packet captures, or document outputs

## Documentation

- [ ] README accurately reflects the scripts present
- [ ] Architecture and metafield map are understandable
- [ ] Usage requirements and risks are stated
- [ ] Screenshots, if added, use synthetic data

## GitHub setup

- [ ] Repository visibility is selected intentionally
- [ ] Repository description and topics are added
- [ ] Default branch protection is considered
- [ ] Secret scanning and dependency alerts are reviewed after publication
- [ ] The placeholder repository URL in CITATION.cff is replaced after publication
